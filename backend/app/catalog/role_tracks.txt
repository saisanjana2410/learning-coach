Learner levels

Beginner: New to the area; guided explanations and exercises.

Foundational: Knows basics; builds small applications and practices core libraries.

Intermediate: Can build projects; learns integrations, testing and debugging.

Advanced: Focuses on system design, performance, security and production reliability.

Track skill level per topic or skill, not just per user. A learner may know Python well but be new to RAG.

Suggested project ladder

AI Engineer

Beginner: Dataset exploration and visualization

Foundational: Regression/classification prediction app

Intermediate: Deep-learning model served through FastAPI

Advanced: Monitored production-style ML pipeline

React Frontend Developer

Beginner: Responsive portfolio

Foundational: React task or weather dashboard

Intermediate: E-commerce UI with API integration

Advanced: Accessible, tested production dashboard

Python Developer

Beginner: CLI expense tracker

Foundational: Automation script backed by SQL

Intermediate: Authenticated FastAPI task API

Advanced: Scalable service with caching, monitoring and CI/CD

GenAI Engineer

Beginner: LLM chatbot

Foundational: Chat-with-documents RAG app

Intermediate: Research agent with tools and citations

Advanced: Evaluated production agent workflow with approvals

MERN Full Stack Developer

Beginner: Responsive interactive website

Foundational: Full-stack notes CRUD app

Intermediate: Multi-user e-commerce or booking app

Advanced: Production MERN app with caching and observability
